# ภาพหน้าจอของระบบ

เก็บไว้ประกอบการส่งงานและใช้อ้างอิงตอนรีวิว ไม่ใช่ไฟล์ที่ระบบเรียกใช้

## แดชบอร์ดสรุป — `dashboard.html` (หน้าที่ 5 ตามข้อกำหนดหัวข้อ 4)

| ไฟล์ | แสดงอะไร |
|---|---|
| `dashboard-01-top.jpg` | หัวเรื่อง แถบแจ้งว่าตัวเลขยังเป็นข้อมูลตัวอย่าง และกล่องตัวเลข 3 กล่องตามสถานะ |
| `dashboard-02-recent-list.jpg` | กล่องตัวเลข และตารางใบลา 5 รายการล่าสุด เรียงจากใหม่ไปเก่า พร้อมปุ่มดูใบลาทั้งหมด |

ต้องใช้ 2 ภาพเพราะเนื้อหาหน้ายาวเกินความสูงหน้าจอที่ถ่ายได้ในภาพเดียว

### สิ่งที่ภาพยืนยัน

- กล่องตัวเลข 3 กล่องนับตามสถานะทั้ง 3 ค่า — รอพิจารณา 3 · อนุมัติ 1 · ไม่อนุมัติ 1
- กดกล่องตัวเลขแล้วไปหน้ารายการที่กรองสถานะนั้นไว้แล้ว
  (ทดสอบแล้ว กด "รอพิจารณา" ได้ผลลัพธ์ 3 ใบ ตรงกับตัวเลขในกล่อง)
- รายการใบลา 5 รายการล่าสุด เรียงตาม `createdAt` จากใหม่ไปเก่า

### ข้อควรรู้

ตัวเลขในหน้านี้ **นับจากข้อมูลตัวอย่างใน `js/data.js` ไม่ได้นับจาก Firestore**
เป็นไปตาม US-11 ที่กำหนดให้การนับจากฐานข้อมูลจริงเป็นงานของสัปดาห์ที่ 7
และเกณฑ์สัปดาห์ที่ 6 ที่ให้อ่านจากฐานจริงได้หน้าเดียวคือหน้ารายการใบลา

หน้าจึงมีแถบสีเหลืองบอกผู้ใช้ไว้ตรง ๆ ไม่ปล่อยให้เข้าใจผิดว่าเป็นตัวเลขจริง
